YMYVerb - estado de desarrollo

Entregado en este paquete:
- proyecto JUCE/CMake para VST3 Windows x64
- DSP: pre-delay manual/sincronizado al host, reverb estéreo, filtros, warmth, ducking, wet/dry y wet-only
- presets de referencia estética para seis sabores de bachata
- GUI vectorial con micrófono luminoso y controles analógicos sobrios
- scripts de compilación Windows e instalador Inno Setup
- workflow opcional de GitHub Actions para compilar en Windows y publicar un artifact

- compilar con JUCE 9.0.4 / Visual Studio 2022
